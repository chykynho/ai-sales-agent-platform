# v0.6 — RAG / Knowledge Base

## Architecture
`Upload -> parse -> chunk -> embeddings -> pgvector/HNSW -> tenant-filtered retrieval -> grounded LLM answer`.

Security: every retrieval filters by authenticated `tenant_id`; document text is treated as untrusted data and cannot override server instructions.

Supported in v0.6: PDF, DOCX, TXT, Markdown. Image OCR/multimodal document understanding arrives later.
