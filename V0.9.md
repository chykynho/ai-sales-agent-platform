# v0.9 — Realtime Voice Foundation

## Objetivo
Adicionar uma camada de Voice AI auditável sem quebrar LangGraph, tools, RAG ou multi-tenancy.

## Arquitetura

```text
transcript de voz (mock nesta fase)
        -> LangGraph/tools/RAG
        -> resposta textual de negócio
        -> OpenAI Realtime WebSocket
        -> áudio PCMU/G.711 μ-law
        -> auditoria voice_sessions / voice_events
```

A integração de telefonia fica preparada para Twilio Media Streams bidirecional (`<Connect><Stream>`). O bridge full-duplex de mídia e barge-in, barge-in e telefonia real fica para v0.10.

## Segurança
- API key OpenAI somente no backend.
- Twilio access token, quando usado, é referenciado por nome de variável de ambiente, não armazenado no banco.
- Sessões e auditoria são sempre tenant-scoped.
- `provider_call_id` é idempotente.

## Testes
O smoke test valida: conexão Realtime real via WebSocket, TwiML bidirecional, LangGraph + `check_price`, geração de áudio real, replay idempotente, checkpoint de voz e auditoria.
