# v0.4 — LangGraph Runtime + PostgreSQL Checkpoints

## Goal

Turn the v0.3 tool-calling backend into a stateful agent runtime without replacing the existing OpenAI provider, ToolService, audit tables, or tenant isolation.

## Graph

```text
START
  |
  v
classify
  |
  +-- needs_human -----------------> handoff ------> END
  |
  +-- pricing / scheduling --------> tool_agent ---> END
  |
  `-- other -----------------------> respond ------> END
```

## State vs runtime context

Checkpointed graph state contains JSON-only conversation data, classification, routing, run IDs, and tool-call IDs. Database sessions, authenticated User objects, LLMService, and ToolService are injected through LangGraph runtime context and are not persisted in checkpoints.

## Persistence

The graph is compiled with `AsyncPostgresSaver`. External thread IDs are always namespaced with the authenticated tenant:

```text
tenant:<tenant_uuid>:thread:<external_thread_id>
```

This prevents two tenants using the same external conversation ID from sharing checkpoint state.

`LANGGRAPH_STRICT_MSGPACK=true` is enabled in the image, and the checkpoint state deliberately stays JSON-only.

## Setup

The checkpoint package owns its internal persistence tables. They are initialized explicitly by:

```bash
python -m scripts.setup_langgraph
```

The upgrade script runs this before bringing up the v0.4 API.

## API

- `GET /api/v1/agent/config`
- `POST /api/v1/agent/threads/{thread_id}/messages`
- `GET /api/v1/agent/threads/{thread_id}/state`
- `GET /api/v1/agent/threads/{thread_id}/history`

## Smoke test

`test_v04.ps1` intentionally restarts the API after the first conversation turn and then reads the same thread again. Passing this test proves the state is in PostgreSQL rather than process memory.

## Intentionally deferred

v0.4 does **not** yet pause the graph with `interrupt()` for human approval. The handoff node is deterministic and marks `human_required=true`. Actual pause/resume with `Command(resume=...)` is the next step so the persistence foundation is proven first.
