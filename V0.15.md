# AI Sales Agent Platform v0.15

A v0.15 introduz a camada de **Multi-Cloud Deployment Readiness**.

## Contratos principais
- uma unica imagem/tag GHCR para `linux/amd64` e `linux/arm64`;
- mesma aplicacao para AWS, Google Cloud, Azure e OCI;
- configuracao e secrets por environment variables;
- lifecycle de banco controlavel sem migration concorrente em replicas;
- liveness `/api/v1/health/live`;
- readiness `/api/v1/health/ready`;
- Docker Compose continua sendo o ambiente local completo com PostgreSQL e Redis.

## Regra de seguranca
A imagem production isolada nao executa migration nem cria usuario bootstrap automaticamente. O Compose local habilita explicitamente esses passos para preservar a experiencia de desenvolvimento.
