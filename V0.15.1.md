# v0.15.1 - Cloud Connectivity Hardening

Esta versao fecha a lacuna entre a imagem multi-arquitetura v0.15.0 e o primeiro deploy real em ambiente serverless.

Principais capacidades:

- Cloud Run `PORT` dinamico;
- Neon PostgreSQL via `DATABASE_URL` com adaptacao de TLS para asyncpg;
- LangGraph/psycopg com URL separada opcional;
- Upstash Redis TLS via `REDIS_URL=rediss://...`;
- EOL LF protegido no Git, Docker build e testes;
- lifecycle de producao seguro: migrations/bootstrap desligados por padrao;
- compatibilidade local preservada.

A versao nao inclui credenciais nem altera volumes/bancos locais existentes.
